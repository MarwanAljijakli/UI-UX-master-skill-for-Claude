# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-05-09

### Added
- Initial public release of the `ui-ux-master` Claude skill.
- 6-phase workflow: audit → domain study → direction → build → test → iterate.
- 5 reference modules: audit framework, domain playbooks (18+ domains),
  design systems, animation library, and testing checklist.
- Prebuilt `.skill` distribution in `dist/`.
- GitHub Actions for automated packaging and release artifacts.
